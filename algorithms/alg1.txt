🐾 Модуль 1: Основы C — Память, Указатели и Биты 🧠

2️⃣ Указатели (Pointers) и их механика 📍
Указатель — это переменная, значением которой является адрес другой ячейки памяти.
💡 Две базовые операции:
& (Взятие адреса / Address-of): Возвращает адрес переменной в памяти.
* (Разыменование / Dereference): Позволяет получить или изменить значение, лежащее по адресу, на который указывает переменная.
C
int x = 10;
int *p = &x; // Переменная 'p' хранит адрес переменной 'x'

printf("%p", (void*)p);   // Выведет адрес (например, 0x7ffeed)
printf("%d", *p);         // Выведет значение 10

*p = 20; // Изменение значения по адресу. Теперь x = 20!
🛑 Капкан синтаксиса Си (Любимый вопрос на внимательность):
C
int* p1, p2;
编```
В этой строчке `p1` — это *указатель на int*, а `p2` — это *обычная переменная int*. Звёздочка привязывается к имени переменной, а не к типу! Чтобы объявить два указателя, нужно писать: `int *p1, *p2;`.

3️⃣ Архитектура памяти: Стек против Кучи 🏗️
Оперативная память, выделяемая программе, делится на несколько сегментов. Главное противостояние для тестов — Стек против Кучи.
A) Стек (Stack)
Механика: Память выделяется по принципу LIFO (Last In, First Out). Работает автоматически при вызове функций.
Что хранится: Локальные переменные, аргументы функций, адреса возврата.
Плюсы: Сверхбыстрая скорость (выделение — это просто сдвиг указателя стека процессора).
Минусы: Ограниченный размер (обычно несколько мегабайт). Если вызвать бесконечную рекурсию, случится Stack Overflow (переполнение стека).
Время жизни: Переменная уничтожается автоматически при выходе из функции (фигурной скобки }).
B) Куча (Heap)
Механика: Огромный пул динамической памяти, управляемый программистом вручную.
Функции выделения (из библиотеки <stdlib.h>):
malloc(size) — выделяет блок памяти указанного размера в байтах. Содержимое блока не инициализируется (там лежит «мусор»).
calloc(num, size) — выделяет память под num элементов размера size и гарантированно обнуляет все байты. Работает чуть медленнее malloc.
realloc(ptr, new_size) — изменяет размер ранее выделенного блока. Может перенести данные на новый адрес, если старому не хватает места.
free(ptr) — освобождает выделенный блок памяти.
⚠️ Главная опасность: Если не вызвать free(ptr), возникнет Memory Leak (Утечка памяти). Память останется занятой до тех пор, пока программа не завершится.

4️⃣ Арифметика указателей и Массивы 📍
Массивы в Си тесно связаны с указателями. Имя массива (без индексов) — это константный указатель на его первый элемент (arr == &arr[0]).
Когда мы прибавляем число к указателю, адрес изменяется не на это число байт, а на число, умноженное на размер типа данных, на который он указывает.
Новый адрес=Текущий адрес+(Смещение×sizeof(Тип))
C
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr; // p указывает на arr[0] (например, адрес 1000)

p = p + 1; // Адрес увеличился на 1 * sizeof(int) = 4 байта.
           // Теперь p указывает на адрес 1004 (элемент arr[1])
printf("%d", *p); // Выведет 20
💡 Трюк для тестов: Запись arr[i] под капотом компилятора превращается в *(arr + i). Из-за коммутативности сложения запись i[arr] тоже абсолютно валидна и вернет тот же элемент!

5️⃣ Битовые операции (Bitwise Operations) 🔢
Работа на уровне отдельных битов числа. Сверхбыстрые операции, выполняемые процессором за 1 такт.
& (Побитовое И / AND): 1 & 1 = 1, остальные 0. Применяется для сброса битов или проверки (наложения маски).
Пример: x & 1 — проверка на чётность. Если результат 1 — число нечётное, если 0 — чётное.
| (Побитовое ИЛИ / OR): 0 | 0 = 0, остальные 1. Применяется для установки битов в единицу.
^ (Побитовое исключающее ИЛИ / XOR): 1 ^ 1 = 0, 0 ^ 0 = 0, разные биты дают 1.
Свойство: x ^ x = 0. Используется для быстрого обнуления регистров или шифрования.
~ (Побитовое НЕ / NOT): Инвертирует все биты (0 превращает в 1, 1 в 0).
<< (Сдвиг влево): Сдвигает биты влево, дописывая нули справа. Эквивалентно умножению на 2
n
 .
Пример: x << 1 — это x⋅2. 1 << n — это быстрый способ получить n-ю степень двойки (создать маску).
>> (Сдвиг вправо): Сдвигает биты вправо. Для положительных чисел эквивалентно целочисленному делению на 2
n
 .
👑 Элитный битовый маркер для экзаменов:
Как проверить, является ли число степенью двойки (2, 4, 8, 16...)?
Формула: (x & (x - 1)) == 0 (при условии, что x>0). У степеней двойки в двоичной записи ровно одна единица (например, 1000), а у x−1 все биты после неё превращаются в единицы (0111). Их пересечение через & всегда даёт 0.

6️⃣ Ошибки работы с памятью и Неопределенное поведение (UB) ⚠️
В Си нет встроенной защиты (Garbage Collector). Ошибки программиста приводят к катастрофам:
Segmentation Fault (Ошибка сегментации): Попытка программы обратиться к сектору памяти, который ей не принадлежит (например, разыменование NULL указателя: int *p = NULL; *p = 10;).
Dangling Pointer (Висячий указатель): Указатель, который продолжает хранить адрес памяти после того, как эта память была освобождена через free(). Обращение по нему ведет к непредсказуемым последствиям.
Double Free: Повторный вызов free() для одного и того же адреса без промежуточного выделения памяти. Приводит к мгновенному падению или уязвимости безопасности.
Buffer Overflow (Переполнение буфера): Запись данных за пределы выделенного массива. Может перезаписать адрес возврата в стеке и сломать логику программы.
💡 Undefined Behavior (UB): Ситуация, когда стандарт языка Си никак не определяет поведение программы (например, выход за границы массива или деление на ноль). Компилятор имеет право сгенерировать абсолютно любой машинный код — программа может работать нормально, упасть или выдать случайный бред.

🧩 Мини-итог
Си предоставляет разработчику хирургический скальпель: можно напрямую переставлять биты через сдвиги и маски, а также вычислять физические адреса элементов. Но за это мы платим отсутствием автоматики — за каждый malloc мы обязаны ответить вызовом free, иначе утечка памяти уничтожит стабильность системы.
